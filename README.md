# Paint Scheme Tracker

A Flutter application for organizing, planning, and tracking paint schemes for Warhammer models and other miniature painting projects.

## Overview

Paint Scheme Tracker is a project management and reference application designed for miniature painters. It allows users to organize their painting projects, document the paints and techniques they use, and keep detailed records of how individual models and armies are painted.

While the application is designed with Warhammer miniature painting in mind, its customizable structure allows it to be used for a wide variety of creative painting projects.

The application is currently under development.

## Features

### Project Management

* Create and manage multiple painting projects
* Organize projects into subprojects
* Track individual models, units, or other project components
* Organize painting progress into individual steps

### Paint Schemes

* Create detailed paint schemes for models and armies
* Assign paints to individual model parts
* Document the order in which painting steps are performed
* Record the techniques used for each step
* Keep painting information organized for future reference

### Customization

The application is designed to be flexible rather than limited to a predefined collection of paints or techniques.

Users can create and manage their own:

* Paints
* Colours
* Model parts
* Painting techniques
* Project structures

This allows the application to adapt to different miniature ranges, painting styles, and creative projects.

### Cross-Platform Access

A future database integration will allow users to synchronize their projects and access their painting information across multiple devices and platforms.

## Purpose

This project was created to provide a structured way for miniature painters to document their paint schemes and reproduce them consistently across models and armies.

It also serves as a practical software development project focused on building a complete application from the ground up, including its user interface, data architecture, and eventual database integration.
